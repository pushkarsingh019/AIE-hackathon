# Literature Review Workbench

This context describes the language for interrogating a curated body of scientific literature as an evidence base for review, comparison, and synthesis.

## Language

**Research Project**:
A user's working context for a literature-review effort, containing one Literature Corpus and the questions, findings, explanations, and reading context associated with it.
_Avoid_: Folder, workspace, project directory

**Literature Corpus**:
A project-scoped curated collection of scientific papers treated as one evidence base for a research question or project.
_Avoid_: PDF folder, papers directory, document dump

**Extracted Corpus**:
The persisted, searchable representation of a Literature Corpus, preserving enough Paper structure to support Evidence Spans.
_Avoid_: Index, vector store, chunk database

**Extraction Quality**:
How reliably a Paper's source material has been converted into searchable, inspectable corpus content.
_Avoid_: OCR status, parser score

**Paper**:
A scientific work included in a Literature Corpus, independent of the file format or source used to ingest it.
_Avoid_: PDF, document, file

**Finding**:
A synthesized statement about what the Literature Corpus shows, which may be generated by the system or supplied by the user for further investigation. Every substantive Finding must be grounded in Evidence Spans unless it explicitly identifies an evidence gap.
_Avoid_: Answer, summary, takeaway

**Answer Segment**:
A sentence, line, or small answer unit that the user can inspect to see the Evidence Spans and Evidence Relations behind it.
_Avoid_: Sentence, claim, line

**Corpus Question**:
Any user question asked against a Literature Corpus, whether it targets one Paper, the whole corpus, or an existing Finding.
_Avoid_: Prompt, query, search

**Paper Question**:
A Corpus Question primarily scoped to one Paper, used to understand, inspect, or interrogate that Paper while still allowing corpus context when it materially changes the answer.
_Avoid_: Single-PDF chat, document question

**Paper Explanation**:
An answer focused on helping the user understand a target Paper, grounded in Evidence Spans from that Paper and optionally contextualized by the Literature Corpus.
_Avoid_: Paper summary, PDF summary

**Reading Context**:
The active Paper or answer area the user is currently focused on, used to interpret follow-up Corpus Questions.
_Avoid_: Chat history, session state

**Idea Question**:
A Corpus Question scoped to an idea, topic, mechanism, method, result pattern, or hypothesis, answered by triaging relevant evidence across the Literature Corpus.
_Avoid_: Corpus summary, literature summary

**Finding Search**:
A Corpus Question that starts from a user-supplied or system-generated Finding and searches the Literature Corpus for supporting, contradictory, similar, or otherwise relevant evidence.
_Avoid_: Evidence check, claim search

**Evidence Span**:
The smallest useful passage, table entry, figure reference, or result excerpt from a Paper that supports, contradicts, or contextualizes a Finding and can be inspected by the user. At minimum, it identifies the Paper, page, section, and exact quoted content.
_Avoid_: Citation, source, chunk

**Evidence Relation**:
The role an Evidence Span plays with respect to a Finding, explaining why that evidence is attached to the answer.
_Avoid_: Relevance score, citation type

**Evidence Set**:
A selected group of Evidence Spans chosen to answer a Corpus Question with useful coverage rather than repeated relevance, including support, disagreement, limitations, close matches, or gaps when they materially affect the answer.
_Avoid_: Top-k results, retrieved chunks

**Candidate Evidence**:
Material that may be relevant to a Finding but does not clearly support or oppose it, shown only when the user asks to inspect uncertainty or broaden the search.
_Avoid_: Weak evidence, low-ranked result

**Disagreement**:
A meaningful difference between Findings or Evidence Spans in the Literature Corpus that should be surfaced rather than smoothed into a single answer.
_Avoid_: Inconsistency, conflict, contradiction

**Background Context**:
General domain explanation used to help interpret Papers or Findings when the user asks for interpretive help, clearly separated from corpus-grounded Findings and not treated as evidence from the Literature Corpus.
_Avoid_: Outside evidence, uncited finding

**Model Flexibility**:
The ability for a Research Project to use configurable models for extraction, retrieval, reranking, and answer synthesis without changing the domain workflow.
_Avoid_: Local-only, model hardcoding
